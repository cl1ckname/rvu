# Клавиши

Принцип: если встаёт вопрос, какую клавишу выбрать, берём стандартную из nvim.
Полную эмуляцию vim не делаем.

Перед командами движения можно указать счётчик (`5j`, `3]c`).

## Глобальные

| Клавиша          | Действие                              |
|------------------|---------------------------------------|
| `q` / `Ctrl-c`   | выход                                 |
| `?`              | шпаргалка по клавишам (`j/k` — прокрутка, `?`/`q`/`Esc` — закрыть) |
| `Ctrl-b`         | скрыть / показать дерево файлов (при показе фокус уходит в дерево) |
| `Tab` / `Ctrl-w w` | переключить фокус: дерево ↔ дифф (скрытое дерево откроется) |
| `Ctrl-w h` / `Ctrl-w l` | фокус на дерево / на дифф      |
| `R`              | перечитать дифф (позиция курсора сохраняется) |
| `zi`             | Page: скрыть / показать неизменённые участки |
| `zM` / `zR`      | Page: скрыть / показать неизменённые участки (явно) |
| `<Space>m`       | переключить режим Scroll ↔ Page (курсор остаётся на той же строке) |

## Просмотр диффа

| Клавиша          | Действие                              |
|------------------|---------------------------------------|
| `j` / `k`        | строка вниз / вверх                   |
| `gg` / `G`       | начало / конец                        |
| `Ctrl-d` / `Ctrl-u` | полэкрана вниз / вверх             |
| `Ctrl-f`/`PgDn`, `PgUp` | экран вниз / вверх (`Ctrl-b` занят под дерево — осознанное отступление от vim) |
| `}` / `{`        | следующая / предыдущая пустая строка (абзац, как в vim; строка из одних пробелов тоже считается пустой) |
| `zz` / `zt` / `zb` | курсор в центр / вверх / вниз экрана |
| `]c` / `[c`      | следующий / предыдущий блок изменений (как в diff-mode nvim); в Page за последним изменением — переход в соседний файл |
| `]f` / `[f`      | следующий / предыдущий файл (в Page курсор встаёт на первое изменение) |
| `c`              | комментарий к текущей строке: вставляется в файл над ней |

## Дерево файлов

| Клавиша          | Действие                              |
|------------------|---------------------------------------|
| `j` / `k`        | вниз / вверх; дифф сразу показывает выбранный файл |
| `l` / `Enter`    | файл — перейти в дифф; каталог — свернуть/раскрыть |
| `h`              | свернуть каталог / перейти к родительскому |

`]c`, `[c`, `]f`, `[f` работают по диффу при любом фокусе.

Стрелки `↑`/`↓` и `PageUp`/`PageDown` тоже работают.

## Строка ввода комментария

| Клавиша          | Действие                              |
|------------------|---------------------------------------|
| `Enter`          | сохранить (локально — вставить в файл, MR — отправить); пустой текст — отмена |
| `Esc` / `Ctrl-c` | отмена                                |
| `Ctrl-w`, `Ctrl-u` | удалить слово / до начала строки (как в insert mode) |
| `Ctrl-h` / `Backspace`, `Delete` | удалить символ слева / справа |
| `←` / `→`, `Home` / `Ctrl-a`, `End` / `Ctrl-e` | движение курсора |
