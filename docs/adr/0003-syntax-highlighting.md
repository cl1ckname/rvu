# ADR-0003: syntect для подсветки синтаксиса

**Статус:** принято · 2026-10-31

## Решение

`syntect` с наборами синтаксисов и тем из `bat` через крейт `two-face`.
Встроенный набор `syntect` не знает TypeScript, TOML, Dockerfile и др.

Подсвечиваем **полный файл**, а не отдельные строки диффа: иначе многострочные
конструкции (строки, комментарии) ломают подсветку. Для старой и новой версий
файла — отдельные проходы, результат кэшируется по файлу.
Если полной версии файла нет — подсвечиваем строки ханка подряд.

## Альтернативы

`tree-sitter` — точнее, но нужны грамматики под каждый язык и больше кода.
