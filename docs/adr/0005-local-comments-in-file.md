# ADR-0005: Локальные комментарии записываются прямо в файл

**Статус:** принято · 2026-10-31

## Контекст

Локальные комментарии нужны, чтобы по ходу чтения диффа оставлять заметки
(FIXME и т.п.) — например, при ревью кода, написанного моделью. Потом их
читает модель или сам автор.

## Решение

- Текст, введённый пользователем, оборачивается в синтаксис комментария
  языка и вставляется **в рабочий файл над текущей строкой**.
- Маркера нет: вставляется ровно то, что введено (`// текст`).
  Настройка префикса — позже.
- Отступ копируется с целевой строки.
- Синтаксис комментария берётся из встроенной таблицы **по названию
  синтаксиса** (`"Rust"`, `"Python"`, …) — того же, что определила подсветка
  (по расширению, имени файла, shebang). Так комментарии работают везде, где
  работает подсветка, без второй логики определения языка.
- Готовых данных нет: метаданные Sublime-синтаксисов (`TM_COMMENT_START`)
  в наборе bat вырезаны (проверено: 0 из 220 синтаксисов). Поэтому таблица
  своя (~130 записей, `src/comment.rs`), тест проверяет, что каждое имя в ней
  существует в наборе синтаксисов.
- Переопределение — `[comments.syntax]` в конфиге по расширению или полному
  имени файла (`Justfile`); имеет приоритет над таблицей.
- Неизвестный тип — ошибка в статусной строке с подсказкой, какой ключ
  добавить в конфиг; файл не трогаем.
- Перед записью файл на диске сравнивается с версией, из которой построен
  дифф; если он изменился — отказ с просьбой перечитать (`R`).
- Смешанные файлы (`<script>` в HTML и т.п.) комментируются синтаксисом
  файла. Позже можно брать язык из scope подсветки на строке.
- Курсор на удалённой строке → вставка над следующей существующей строкой
  (там, где удалённая строка была).
- Вставленная строка становится обычным изменением и видна в диффе как Added.
- Ввод — однострочный, в строке внизу экрана.

## Последствия

- Нет отдельного хранилища и синхронизации.
- Работает, только когда сторона «new» диффа — рабочее дерево. Для целей
  вида «коммит ↔ коммит» решим отдельно, когда до них дойдём.
- В режиме MR локальные комментарии недоступны: `c` создаёт комментарий в MR.
