# ADR-0002: git2 (libgit2) для работы с локальным репозиторием

**Статус:** принято · 2026-10-31

## Контекст

Нужно получать дифф (сначала рабочее дерево ↔ индекс, потом ветки, коммиты,
диапазоны) и полные версии файлов с обеих сторон (для режима Page).

## Варианты

1. **`git2`** — биндинги к libgit2. Зрелые, умеют дифф с ханками и номерами
   строк, merge-base, revparse (`main..HEAD`, `main...HEAD`), блобы из индекса.
2. **`gix`** (gitoxide) — чистый Rust, но API диффа рабочего дерева пока
   менее зрелый.
3. **Вызов `git diff` и парсинг вывода** — уважает пользовательский
   `.gitconfig`, но нужен свой парсер и отдельные вызовы для содержимого файлов.

## Решение

`git2`. Все цели диффа выражаются через `revparse` + `diff_tree_to_index` /
`diff_index_to_workdir` / `diff_tree_to_tree`.

## Последствия

- C-зависимость (libgit2), собирается через крейт, на Linux не проблема.
- Внешние diff-драйверы и `diff.algorithm` из `.gitconfig` не применяются.
  Если это станет проблемой — вернёмся к варианту 3.
