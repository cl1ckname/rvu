# ADR-0001: ratatui + crossterm + tokio

**Статус:** принято · 2026-10-31

## Контекст

Нужен TUI на Rust с отзывчивым интерфейсом: сетевые запросы к GitLab
не должны блокировать отрисовку.

## Решение

- `ratatui` — стандарт де-факто для TUI на Rust, активно развивается.
- `crossterm` — бэкенд терминала, есть async `EventStream`.
- `tokio` — фоновые задачи (HTTP, загрузка диффа), единый event loop
  на каналах.

## Последствия

- Состояние приложения живёт в одной задаче, фоновые задачи присылают
  результаты сообщениями — без `Mutex` вокруг состояния.
