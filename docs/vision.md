# rvu — видение продукта

## Что это

`rvu` — терминальный клиент для ревью кода. Показывает изменения из git
(локальные или из merge request GitLab) и позволяет оставлять комментарии
прямо на просматриваемой строке.

## Для кого и зачем

Основной пользователь — разработчик, живущий в терминале и nvim.

Ключевые сценарии:

1. **Ревью кода, написанного моделью / собой.** Открываю `rvu` в репозитории,
   читаю `git diff`, по ходу чтения оставляю `FIXME`-заметки прямо в исходниках.
   Потом отдаю их модели (или себе) на исправление.
2. **Ревью MR в self-hosted GitLab.** Открываю MR по URL, читаю дифф,
   оставляю инлайн-комментарии, которые сразу уходят в GitLab.

## Ключевые возможности

- **Два режима просмотра:**
  - *Scroll* — непрерывная лента диффа всех файлов, как `git diff`.
  - *Page* — файл показывается целиком, изменённые ханки подсвечены внутри
    файла (удалённые строки — красным на своих местах), файл пролистывается.
- **Дерево изменённых файлов** сбоку.
- **Подсветка синтаксиса** в обоих режимах.
- **Локальные комментарии:** текст оборачивается в комментарий языка файла
  и вставляется в файл **над** текущей строкой. Никакого отдельного хранилища.
- **GitLab MR:** просмотр диффа через API и инлайн-комментарии.
- **Навигация в стиле nvim:** при выборе клавиш ориентируемся на стандартные
  клавиши nvim. Полной эмуляции vim не делаем.
- **Конфигурация** в TOML-файле по XDG-пути (`~/.config/rvu/config.toml`).

## Не цели (по крайней мере пока)

- Полноценный редактор кода внутри `rvu`.
- Поддержка Windows / macOS (только Linux).
- Пословная (word-level) подсветка изменений — подсвечиваем строку целиком.
- Отдельная база локальных комментариев, синхронизация их с GitLab.
