# Roadmap

Статусы: ⬜ не начато · 🟡 в работе · ✅ готово

## M0 — Скелет ✅

- ✅ `git init`, `cargo init`, документация
- ✅ CLI (`clap`): `rvu`, `rvu <mr-url>`
- ✅ Загрузка конфига из `$XDG_CONFIG_HOME/rvu/config.toml`
- ✅ TUI-цикл (`ratatui` + `crossterm`): открыть, отрисовать пустой экран, выйти по `q`
- ✅ Логи через `tracing` в файл (`$XDG_STATE_HOME/rvu/rvu.log`)

## M1 — Локальный дифф, режим Scroll ✅

- ✅ Загрузка `git diff` (рабочее дерево ↔ индекс) через `git2`
- ✅ Модель `Changeset` / `FileDiff` / `Hunk` / `DiffLine`
- ✅ Дерево изменённых файлов, переключение фокуса, превью файла при движении по дереву
- ✅ Режим Scroll: лента диффа всех файлов (в порядке дерева)
- ✅ Подсветка синтаксиса (`syntect` + наборы `bat` через `two-face`) + фон для добавленных/удалённых строк
- ✅ Навигация: `j/k`, `gg/G`, `Ctrl-d/u`, `Ctrl-f/b`, `zz/zt/zb`, `]c/[c`, `]f/[f`, счётчики
- ✅ Обновление диффа (`R`) с сохранением позиции курсора
- ✅ Справка по клавишам (`?`)

## M2 — Режим Page ✅

- ✅ Файл целиком (новая версия) с вклеенными удалёнными строками
- ✅ Подсветка изменённых строк внутри файла
- ✅ Переключение режимов `<Space>m` с сохранением позиции курсора
- ✅ `]f`/`[f` и дерево переключают файл; `]c`/`[c` за последним изменением
  переходят в соседний файл
- ✅ Режим при запуске — `ui.default_mode` в конфиге
- ✅ Сворачивание неизменённых участков (`zi`/`zM`/`zR`), `[page]` в конфиге

## M3 — Локальные комментарии ✅

- ✅ Строка ввода внизу экрана (`c`), редактирование как в insert mode
- ✅ Синтаксис комментария по синтаксису подсветки (~130 языков) + переопределение в конфиге
- ✅ Вставка над текущей строкой с сохранением отступа и стиля переводов строк
- ✅ Удалённая строка → вставка на место, где она была
- ✅ Защита: файл изменился на диске — отказ
- ✅ Перечитывание диффа после вставки, курсор на новом комментарии

## M4 — GitLab MR: просмотр ✅

- ✅ Разбор URL MR (`https://host[:port]/group/sub/project/-/merge_requests/123[/...]`)
- ✅ Токен из конфига (`token` / `token_env` / `token_command`), инстанс по хосту
- ✅ Загрузка MR (`diff_refs`) и диффов через `/diffs` с пагинацией
- ✅ Полные версии файлов (подсветка, режим Page) — в фоне, 8 параллельных запросов
- ✅ `R` перезагружает MR в фоне
- ✅ Понятные ошибки: токен (401), нет доступа/неверный URL (404), нет инстанса в конфиге

## Цели локального диффа ✅

- ✅ Аргументы как у `git diff`: `--staged [<rev>]`, `<rev>`, `A..B`, `A...B`
  (пустая сторона — `HEAD`), `C^!` (один коммит, корневой — против пустого дерева)
- ✅ Поиск переименований
- ✅ Комментарии: если новая сторона — коммит или индекс, пишем в рабочее
  дерево, только когда файл там совпадает с просматриваемой версией

## M5 — GitLab MR: инлайн-комментарии ⬜

- Создание discussion с `position` на выбранной строке
  (добавленной / удалённой / контекстной)

## Потом (без порядка)

- Отображение существующих тредов MR, ответы, resolve, approve, draft notes
- Настройки маркера локального комментария (префикс вроде `FIXME(rvu):`),
  список и удаление своих заметок
- Многострочные комментарии через `$EDITOR`
- Переназначение клавиш в конфиге
- Side-by-side режим
- Поиск `/`, `n/N`
- Открыть текущую строку в nvim (`gf`)
- Раскрытие отдельной свёртки (`zo`/`zc`/`za` на строке `⋯ N unchanged lines`)
- Отслеживание изменений файлов (auto-refresh)
- Горизонтальный скролл длинных строк (сейчас обрезаются)
- Прокрутка окна справки на маленьких терминалах
- Фоновая загрузка локального диффа (сейчас синхронно; на больших репо может подтормаживать)
- GitHub PR
