# rvu

TUI-клиент для ревью кода на Rust (ratatui). Продуктовая документация — в `docs/`.

## Соглашения

- Документация и ADR — на русском. UI, код, комментарии в коде, сообщения об ошибках — на английском.
- Только Linux.
- Клавиши: при выборе ориентируемся на стандартные клавиши nvim (`docs/keybindings.md`).
- Существенные технические решения фиксируем новым ADR в `docs/adr/NNNN-*.md`.
- После завершения пункта roadmap обновляем статус в `docs/roadmap.md`.
- Любая новая настройка — сразу в `src/config.rs` (с дефолтом), `assets/config.toml` и `docs/config.md`.
- Новое действие (`Action`) — добавить в `HELP_SECTIONS` (шпаргалка `?`), иначе упадёт тест.
- Перед завершением задачи: `cargo build`, `cargo test`, `cargo clippy` без предупреждений.
- Логи — только через `tracing` (пишутся в `~/.local/state/rvu/rvu.log`), stdout занят TUI.
